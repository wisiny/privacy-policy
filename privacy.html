Privacy Policy *

This privacy policy outlines how the "SP Bid Calculator" extension collects, uses, and protects your data. By using this extension, you agree to the practices described below.

1. Data Collection

The "SP Bid Calculator" extension may collect and store the following data locally on your device:

  • User preferences, such as default bid settings and adjustment factors.
  • Locally cached calculation results to improve performance.

Note: This extension does not collect or store personally identifiable information (PII) or share user data with third parties.

2. Permissions

The extension requires the following permissions:

  • Storage: To save user preferences and cache calculation results locally.
  • Remote Code: To enable real-time updates and ensure compatibility with evolving requirements.

3. Data Usage

All data collected is used exclusively for the following purposes:

  • To provide accurate bid calculations based on user inputs.
  • To enhance the functionality and user experience of the extension.
  • To locally save user preferences for convenience.

4. Security

We prioritize your privacy and security. All data is stored securely using Chrome's storage API. Remote updates are delivered via secure channels to ensure data integrity.

5. User Control

You have full control over the extension's data usage. You can manage or delete locally stored data via Chrome's extension settings or by uninstalling the extension.

6. Changes to This Policy

This privacy policy may be updated periodically to reflect changes in functionality or data handling practices. Updates will be reflected in the extension's version history.
